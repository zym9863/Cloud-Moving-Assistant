# 云搬家助手 (Cloud Moving Assistant)

[中文](README.md) | [English](README_EN.md)

一个智能化的网页应用，帮助用户生成个性化搬家清单，让搬家过程更加轻松高效。

## 项目简介

云搬家助手是一个简单易用的网页应用，通过智能分析用户需求，为用户生成个性化的搬家清单。应用采用现代化的UI设计，提供了直观的用户界面和流畅的交互体验。

## 功能特点

- **一键生成搬家清单**：只需点击按钮，即可生成包含多个分类的详细搬家清单
- **分类整理**：物品按照不同房间和用途进行分类，便于规划和整理
- **交互式清单**：可以点击标记已完成的物品，方便跟踪搬家进度
- **多种导出选项**：支持保存、分享和打印功能，满足不同场景需求
- **响应式设计**：完美适配各种设备，从手机到桌面电脑

## 技术栈

- HTML5
- CSS3 (包含动画和响应式设计)
- JavaScript (原生JS)
- 本地JSON数据存储

## 使用方法

1. 打开`index.html`文件或访问部署后的网站
2. 点击"生成搬家清单"按钮
3. 等待系统生成个性化的搬家清单
4. 查看分类整理好的物品清单
5. 点击物品可以标记为已完成
6. 使用保存、分享或打印功能导出清单

## 物品分类

应用包含以下物品分类：

- 厨房用品
- 卧室用品
- 客厅用品
- 卫生间用品
- 衣物
- 书籍文件
- 杂物

## 本地开发

要在本地运行此项目：

1. 克隆或下载此仓库
2. 使用浏览器打开`index.html`文件
3. 无需安装任何依赖，即可开始使用

## 自定义物品清单

如需自定义物品清单，可以编辑`items.json`文件，按照既定格式添加或修改物品类别和具体物品。
