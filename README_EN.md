# Cloud Moving Assistant

[中文](README.md) | [English](README_EN.md)

An intelligent web application that helps users generate personalized moving checklists, making the moving process easier and more efficient.

## Project Overview

Cloud Moving Assistant is a user-friendly web application that intelligently analyzes user needs to generate personalized moving checklists. The application features a modern UI design, providing an intuitive user interface and smooth interaction experience.

## Key Features

- **One-Click Checklist Generation**: Simply click a button to generate a detailed moving checklist with multiple categories
- **Categorized Organization**: Items are categorized by different rooms and purposes, making planning and organizing easier
- **Interactive Checklist**: Click to mark completed items, convenient for tracking moving progress
- **Multiple Export Options**: Support for saving, sharing, and printing functions to meet different scenario needs
- **Responsive Design**: Perfectly adapts to various devices, from mobile phones to desktop computers

## Technology Stack

- HTML5
- CSS3 (including animations and responsive design)
- JavaScript (vanilla JS)
- Local JSON data storage

## How to Use

1. Open the `index.html` file or visit the deployed website
2. Click the "Generate Moving Checklist" button
3. Wait for the system to generate a personalized moving checklist
4. View the categorized item list
5. Click on items to mark them as completed
6. Use the save, share, or print functions to export the checklist

## Item Categories

The application includes the following item categories:

- Kitchen Supplies
- Bedroom Items
- Living Room Items
- Bathroom Supplies
- Clothing
- Books and Documents
- Miscellaneous Items

## Local Development

To run this project locally:

1. Clone or download this repository
2. Open the `index.html` file in a browser
3. No dependencies need to be installed to start using it

## Customizing the Item List

To customize the item list, edit the `items.json` file and add or modify item categories and specific items according to the established format.
